# Tetris Battle

FastAPI로 제공하는 브라우저 테트리스 게임입니다.

## 현재 단계

- 40 LINES: 40줄을 지우는 시간을 측정합니다.
- TIME ATTACK: 120초 동안 점수를 모읍니다. 40줄을 넘어도 계속 진행하며, 블록이 쌓이면 조기 종료됩니다.
- 두 모드 모두 3초 카운트다운 후 시작하며 낙하 속도는 1초에 1칸으로 고정됩니다.
- 7-bag, SRS 회전, 홀드, 고스트, T스핀/미니, 콤보, B2B, 퍼펙트 클리어를 지원합니다.
- 잠금 지연은 500ms이며 착지 후 이동·회전으로 최대 15회 갱신합니다. 180도 회전은 시계 방향 90도 회전 두 번을 한 동작으로 처리합니다.
- 착지·하드드롭·줄 삭제 효과, 합성 효과음과 배경음, 개별 볼륨 및 음소거 설정을 제공합니다.
- 푸른 파스텔 배경과 둥근 카드·버튼, 선명한 네이비 게임 보드를 제공합니다.
- 상단의 **블록 스킨**에서 젤리(광택), 모찌(표정), 크리스탈(보석), 네온(빛나는 테두리), 레트로(아케이드) 중 하나를 선택합니다. 선택 즉시 현재 블록·쌓인 블록·고스트·홀드·NEXT에 반영되며 새로고침 후에도 유지됩니다. 선택 중 게임은 계속 진행됩니다.
- 스킨은 외부 이미지나 폰트 다운로드 없이 Canvas로 그리며, 게임 규칙과 점수는 스킨에 영향을 받지 않습니다.
- 결과에 시간, 점수, 삭제한 줄, 놓은 블록, 초당 블록 수(PPS), 최대 콤보, T스핀/4줄 삭제/퍼펙트 클리어 횟수를 표시합니다.
- 최고 기록과 모드별 최근 10판, 설정은 브라우저에 저장합니다. 기존 40줄 최고 기록도 유지합니다.
- 40줄 최고 시간은 완주한 판만 반영합니다. 타임어택 최고 점수는 조기 종료한 판도 반영합니다. R로 중단하고 재시작한 판은 기록하지 않습니다.
- 점수는 레벨 배수 없이 고정하며, 일반 삭제는 100/300/500/800점, T스핀은 400/800/1200/1600점, 미니는 100/200/400점입니다. B2B는 어려운 줄 삭제 기본 점수의 1.5배, 콤보는 두 번째 연속 삭제부터 50점씩 추가됩니다.
- 설정창을 열어도 게임은 계속 진행됩니다.
- `GET /health` 상태 확인 API

## 실행

Python 3.12 이상과 Node.js 22 이상이 필요합니다. `node`가 PATH에 있어야 합니다.
FastAPI가 서버용 Node 엔진을 자동 실행·종료합니다. 솔로와 대결이 같은 `frontend/js/engine.js` 규칙을 사용합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 열고, 상태 확인은 `http://127.0.0.1:8000/health`에서 할 수 있습니다.

## 온라인 1대1 대결

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 1558 --ws-max-size 4096
```

내 PC에서는 `http://127.0.0.1:1558/battle`, 다른 사람은 `http://서버PC의IP:1558/battle`로 접속합니다.
페이지와 WebSocket은 접속한 호스트·포트를 그대로 사용합니다. HTTPS 뒤에서는 자동으로 WSS를 사용합니다.
외부 네트워크 접속 시 해당 포트의 방화벽 허용/공유기 포트 전달이 필요합니다.

1. **ONLINE DUEL**에서 닉네임·스킨·조작 설정을 선택합니다.
2. 방을 만들고 6자리 코드 또는 초대 링크를 공유합니다. 방 목록에서도 참가할 수 있습니다.
3. 두 명 모두 준비하면 3초 후 같은 7-bag 순서로 대결합니다.
4. 상대 보드·보낸 공격·받을 공격을 실시간 확인하며 방 전용 채팅을 사용할 수 있습니다. Enter로 채팅을 열고 Escape로 입력창을 벗어납니다.
5. 먼저 블록이 넘치면 패배합니다. 결과 후 둘 다 다시 준비하면 재대결합니다. 기권·방 나가기·접속 종료는 패배이며 네트워크 단절은 약 20초 이내에 판정합니다.

| 공격 | 쓰레기 줄 |
| --- | --- |
| 싱글 / 더블 / 트리플 / 테트리스 | 0 / 1 / 2 / 4 |
| T스핀 싱글 / 더블 / 트리플 | 2 / 4 / 6 |
| 미니 싱글 / 더블 | 0 / 1 |
| B2B | +1 |
| 퍼펙트 클리어 | +10 |
| 연속 2~3 / 4~5 / 6~7 / 8회 이상 삭제 | +1 / +2 / +3 / +4 |

내 공격은 받을 공격부터 FIFO 순서로 상쇄하고, 남은 줄만 상대에게 보냅니다.
쓰레기 줄은 1.2초 예고 후 **줄을 지우지 않은 착지**에서 최대 8줄씩 올라옵니다.
줄을 지우면 상승을 유예합니다. 한 공격 묶음의 구멍 위치는 동일하며 서버가 결정합니다.
낙하 속도는 대결에서도 1초에 1칸으로 일정합니다.

서버가 이동·회전·줄 삭제·공격·승패를 판정하며 클라이언트의 보드나 공격량 신고는 받지 않습니다.
방은 최대 2인, 채팅 200자/최근 60개, 로비 최대 64개 방입니다.
현재는 로그인·관전·재접속 복구·영구 대결 기록 없는 소규모 대결용입니다.
방과 채팅은 메모리에 있으므로 서버를 재시작하면 사라집니다. **Uvicorn 단일 worker로 실행**하세요.
Windows에서는 Node 자식 프로세스 구동을 위해 위 명령처럼 `--reload` 없이 실행합니다.

## 테스트

```powershell
pytest
node --test tests/engine.test.cjs tests/battle.test.cjs
$env:TTRS_URL='http://127.0.0.1:1558'
node tests/browser.cjs
node tests/battle-browser.cjs
```

브라우저 검증은 실행 중인 서버, Node.js 22 이상, Chrome을 사용합니다. 기본 주소는 `http://127.0.0.1:8000`이며 `TTRS_URL`, `TTRS_CHROME` 환경 변수로 변경할 수 있습니다. 별도의 테스트 프로필에서 실제 키 입력, 40줄 완료, 효과음 신호·음소거, 저장·복원, 120초 전체 타임어택을 검사합니다. 캡처와 결과는 Git에서 제외된 `.test-artifacts/`에 남습니다. 사용자의 브라우저 기록에는 영향을 주지 않습니다.

대결 브라우저 테스트는 기본 1558 포트를 사용하며, 독립 브라우저 컨텍스트 세 개로 방 정원/채팅 격리/동시 시작/보드 동기화/실제 줄 삭제 공격/쓰레기 상승/기권/재대결/접속 종료/모바일 레이아웃을 검증합니다.

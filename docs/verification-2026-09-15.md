50명 부하 검증은 자동 클라이언트이며, 외부 네트워크의 실제 사용자 50명 검증은 아닙니다. 원본 전체 전송량은 약 8.3 MiB/s(압축 전, 50명 합산)였습니다. 인터넷 환경에서는 업로드 대역폭·지연·브라우저 성능에 따라 달라집니다. 공인 주소 확인 또한 서버 PC에서 수행한 것으로 별도 외부 회선 검증을 의미하지 않습니다.

테스트용 화면 캡처는 `.test-artifacts/`에 저장했습니다. 테스트 컨테이너는 종료했으며, 테스트 DB 볼륨은 운영 DB와 별개로 보존했습니다. 운영 DB에는 테스트 랭킹을 복사하지 않았습니다.

운영 시 유의: HTTP 비밀번호 전송은 암호화되지 않으므로 실제 계정 공개 서비스 전 HTTPS가 필요합니다. 서버 재시작 시 진행 중인 방/채팅은 사라지지만 이미 저장된 기록은 PostgreSQL 볼륨에 유지됩니다.

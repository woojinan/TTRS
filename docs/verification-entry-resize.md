# 입장 화면 · 마우스 크기 조절 · 공격 예고 검증

2026-09-15, 운영과 분리된 `ttrs-preview`의 PostgreSQL 및 실제 Chrome으로 검증했습니다.

- Node 규칙/회전/대결 단위 검사: 62개 통과.
- Python API/인증/입장 제한/기존 게스트 전환: 15개 통과.
- 입장 화면·드래그·공격 높이: 5개 브라우저 시나리오 통과.
- ARENA 기능: 8개 브라우저 시나리오 통과.
- 실제 대결 공격/상쇄/재대결: 10개 브라우저 시나리오 통과.
- 기존 설정·스핀: 10개 브라우저 시나리오 통과.
- 기존 솔로: 실제 120초 타임어택 포함 20개 브라우저 시나리오 통과.
- 총 130개 검사 및 별도 50개 자동 WebSocket 클라이언트 검사 통과. 외부 회선의 실제 사용자 50명 검증은 아닙니다.

주요 확인 사항:

1. 보드 300px, 채팅 높이/너비 300px 기본값 유지. 별도 크기 조절 버튼 제거.
2. 마우스 가장자리/모서리 드래그, 커서 모양, 1:2 보드 비율, 최소/최대 크기, 저장/복원 확인.
3. 공격 대기 7줄·예고 완료 3줄에서 세로 7칸(빨강 3, 노랑 4), 보드 높이 35% 예고선 확인. 크기 조절 후 비례 유지, 20줄 초과/상쇄로 0줄 전환 확인.
4. 로그인/회원가입/게스트 명시적 입장, 초대 링크 복귀, 외부 URL로의 리다이렉트 차단 확인.
5. `guest_숫자5~6자리` 고유 닉네임 및 기존 게스트 사용자 ID 유지 확인.
6. 방장 준비 버튼 없음. 다른 참가자 한 명만 준비해도 시작 가능하며 준비하지 않은 인원도 함께 참가. 빈 방 이름은 서버가 `닉네임s_room`으로 생성.

발견한 좁은 화면 넘침을 수정했으며, 예약된 애니메이션 프레임 시간이 키 입력 시간보다 앞서 기록될 수 있는 문제도 실제 콜백 시각을 사용하도록 보완했습니다.
